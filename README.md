# ULaLo 🌍

ULaLo is a simple web application that generates a **16 letters unique code for any location** using its latitude and longitude.
I am uncertain of its practical applications; my intention was simply to design a concise and unique code, which I successfully accomplished.

---

## ✨ Features
- **Location to Code**: Enter latitude and longitude, get a unique code instantly.
- **Code to Location**: Decode a ULaLo code back into coordinates.
- **Lightweight & Fast**: Built with Next.js and exported as a static site.

---

## 🚀 How It Works
1. Input your latitude and longitude.  
2. ULaLo generates a short, unique alphanumeric code.  
3. Share this code with others — they can decode it back to the exact location.

---

## 🛠️ Tech Stack
- **[Next.js](ca://s?q=Next.js_overview)** for the frontend framework
- **Static Export** for GitHub Pages hosting
- **TypeScript** for type safety
- **react-leaflet** for interactive maps
